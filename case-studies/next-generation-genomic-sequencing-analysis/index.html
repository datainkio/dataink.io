Product & Platform

Next-Generation Genomic Sequencing Analysis

The Seven Bridges Genomics Platform resolves the information bottleneck of genomics research by providing a central hub for teams to store, analyze, and jointly interpret their bioinformatic data. The NIH’s National Cancer Institute uses SBG to facilitate research and collaboration on petabyte-scale datasets like The Cancer Genomics Atlas (TCGA) in an environment that supports rapid discovery. Scientists use the Platform to collaborate on their research from anywhere in the world, bringing their questions to the data.

Overview

01 / Problem
Seven Bridges built IGOR so biologists who can't code could run sequencing analysis in the cloud. Users signed up but didn't stay, and flat file storage fragmented their data.
02 / Design Challenge
Russ owned product design for the platform. He wrote the specs, set the roadmap and directed the team, with two months and a fixed backend.
03 / Approach
He cut sign-up to three fields and gave new users four entry points. The database couldn't hold relationships, so the interface did: inferred metadata, tags as pseudo-objects, visible cross-file links.
04 / Outcome
He set the metric before the work (new users completing a first task) and a baseline: 85 task starts, Jun–Dec 2012. No outcome data survives.

Process + Evidence Plates

    • Fig 01 / Information Architecture

    Decision: Fix data fragmentation through metadata, not storage

    Result: Files stayed findable and connected without waiting on a new backend

    • Fig 02 / Interaction Design

    Decision: Cut registration to three fields

    Result: Sign-up took seconds, and verification moved to a later, gentler prompt

    • Fig 03 / User Flow Analysis

    Decision: Greet new users with four low-commitment entry points

    Result: New users found a first task quickly instead of facing an empty workspace

    • Fig 04 / Interaction Design

    Decision: Design task error and pending states before the happy path

    Result: Failed and running computations explained themselves and offered a next step

    • Fig 05 / Experience Design

    Decision: Automate alignment, variant calling and annotation behind a graphical interface

    Result: Biologists ran sophisticated analyses without writing code

    • Fig 06 / Personas

    Decision: Design for several research communities, not one generic scientist

    Result: Rare-disease, cancer and evolutionary biologists each used IGOR to make discoveries in their own field
