Callout

A short note, tip, or warning block with a tone, an optional title, and text, html, or a call body.

Specimens

Params

ParamTypeDescription
titlestringOptional heading, rendered as h3.
tonestringinfo (default), success, warning, or danger. Unknown values fall back to info.
ariaLabelstringaria-label on the <aside>. Defaults to “Callout”.
classesstringAppended as-is to the <aside>. No classes filter.
htmlstringHTML, output with safe. Used when there is no {% call %} body.
textstringPlain text in a <p>. Used when neither a caller body nor html is set.

Notes

Tones are info (the default), success, warning, and danger. An unknown tone falls back to info. The classes param accepts a string or a variant map.
