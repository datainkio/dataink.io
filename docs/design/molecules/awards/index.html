Awards

A recognition section that groups award records by organization and renders each group as an award-organization card.

Specimens

Params

ParamTypeDescription
awardsarrayArray of award records, grouped via the groupByOrg filter.
classesstring | variant map | arrayAppended to the <section> root. See the Component API spec.

Notes

Renders nothing when awards is empty. The section heading and the awards-heading id come from the section frame, so use one instance per page.
