presets/card

Card motion preset — CARD_PARALLAX, the lg+ body-parallax offsets used by the card-motion parallax molecule.

CARD_PARALLAX = { bodyYPercent, bodyYOrigin }. Not to be confused with the parallax card profile in profiles.js (CARD_PARALLAX_PROFILE), which selects the variant per breakpoint.
